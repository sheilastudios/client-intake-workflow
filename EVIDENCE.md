## Historical results, not new runs

The June 8, 2026 case account reports successful prototype page/API and syntax checks, duplicate handling, rejection of a disallowed action, and **64 passing client-lane tests**. It also distinguishes a code correction from restarting stale processes. These are retained historical statements; the underlying execution output was not independently reproduced in this documentation review.

The June 1, 2026 regression account reports **three passing tests** for selected redaction and operator-context handling. Those counts belong to those dated accounts. They are not a count of the current, subsequently expanded test files, and they do not represent new runs performed for this repository.

The source inspection supports the specific implementation descriptions. It does not turn either historical account into an independently repeated test. The synthetic journey in the case study is an illustration, not additional verification.

## Important limits

- No current deployment, availability, authentication configuration or production security audit was performed for this showcase.
- Application origin checks are not operator authentication. Historical protected deployment behavior must not be attributed to those checks alone.
- Exact-repeat recognition does not authenticate a changed submission or grant access to another record.
- A follow-up status is not proof that verification is complete; a promotion flag is not proof that a client environment has been provisioned.
- Filesystem checks and selected regression cases do not prove complete race resistance or isolation outside the checked helpers.
- The historical privacy account left broader cross-channel and related-organization confidentiality questions open. This showcase does not silently close them.
- No paid-client outcome, security certification, exhaustive adversarial evaluation or performance improvement is claimed.

This is evidence for a bounded engineering case study: what was built, which failure cases were addressed and where verification ends.
